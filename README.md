# Building Material Quantity & Cost Estimation System Using MATLAB

## Project Overview
A MATLAB-based system developed to estimate building material
quantities and their corresponding construction costs.

## Objectives
- Estimate building material quantities
- Calculate cement, sand and aggregate requirements
- Estimate reinforcement steel quantities
- Calculate plastering and flooring quantities
- Estimate overall material costs

## Technologies Used
- MATLAB
- Civil Engineering Quantity Estimation
- Construction Cost Estimation

## Modules
1. Earthwork and Excavation
2. RCC Material Estimation
3. Steel Quantity Estimation
4. Plastering Quantity Estimation
5. Flooring Quantity Estimation
6. Material Cost Estimation

## How to Run
1. Open MATLAB.
2. Open the project folder.
3. Run the main MATLAB file.
4. Enter the required building dimensions.
5. View the calculated quantities and costs.
